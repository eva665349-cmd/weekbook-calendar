# Weekbook Calendar

一个可直接部署到 GitHub Pages 的响应式周记 / 月历应用。它是纯静态网页，不依赖 ChatGPT、不需要登录或后端；记录保存在当前浏览器的 `localStorage` 中。

## 发布到 GitHub Pages

仓库已经包含 GitHub Pages 自动发布流程。将本项目推送到 GitHub 后：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中将 Source 设为 **GitHub Actions**。
3. 推送到 `main` 分支，或在 **Actions** 页面手动运行 `Deploy Weekbook to GitHub Pages`。
4. 部署完成后，地址通常为 `https://你的用户名.github.io/仓库名/`。

每次更新 `main` 分支都会自动重新发布。网页使用相对路径，因此既支持项目主页，也支持自定义域名。

## 本地预览

在项目目录启动任意静态文件服务器，并将根目录指向 `dist/`。例如：

```sh
python3 -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

## 数据说明

- 数据只保存在当前浏览器和当前设备中，不会上传到 GitHub。
- 清除浏览器网站数据会同时删除记录。
- 不同设备不会自动同步；如果以后需要同步，可以再增加导入 / 导出或云端存储。

## 功能

- 日期纵向、分类横向的周视图
- 上一周、下一周与回到今天
- 单元格内多条记录，以及新增、编辑、删除
- 分类设置统一为左下角的单一入口，可新增、删除、重命名、排序和设置颜色；手机端同一入口位于底栏最左侧
- 每个一级分类可自行添加、重命名、删除子类别；新增子类别会自动获得同色系且未被使用的颜色，也可手动调整
- 预置五个一级分类：阅读、视听、学习、Body、Flow；主色依次为 `#8B86BE`、`#D7ADBC`、`#EAB668`、`#CCD48D`、`#8BAEB6`
- 影视、Podcast、英语、西语、跳舞、无氧、画画、软笔等子类别采用各自主分类的协调色，并保持足够区分度且不重复
- 记录文字颜色可跟随子类别 / 一级分类，也可独立设置
- 更窄、更修长的五分类周网格
- 周记会按当前分类数量自动等分页面并调整信息密度，新增或删除分类后仍可完整显示全部分类，无需横向滑动
- 针对 iPhone Safari 优化安全区、底部导航、弹窗、输入框与触控尺寸；手机月历完整显示七列
- 手机周记采用截图友好的紧凑总览：滑到周表起点即可在一屏查看周一至周日，单格超过三条时显示剩余条数
- 月历摘要、带勾选状态的一级分类与子类别多选筛选（可只看“跳舞”，或组合显示 Body、Flow 等）；“全部”再次点击可清空显示
- 记录可填写投入时长，时长只在独立的数据分析页统计，不在周记和月历显示
- 数据分析支持周 / 月切换，界面只保留圆环总览、时间走向和星期节奏
- 一级分类与子类别均按“类目 / 用时”和“占比 / 环比”两列显示；环比增加直接显示百分比，减少以绿色负百分比显示
- 浏览器本地持久化
- 首次打开自动载入示例数据
